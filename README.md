# Equipe03 Express

Projeto front-end comercial para uma empresa de fretes, pontos de coleta e gestão de entregas.

## Proposta

A Equipe03 Express foi adaptada para o mercado de logística e e-commerce, com linguagem profissional inspirada em plataformas reais de frete: cotação, postagem, rastreamento, pontos de coleta e painel operacional.

## Funcionalidades

- Página inicial com copy comercial voltada para lojistas e pequenos negócios.
- Simulação de cotação de frete com origem, destino, peso, preço e prazo estimado.
- Busca por pontos de coleta usando CEP, cidade ou bairro.
- Consulta de CEP via ViaCEP quando o usuário informa um CEP válido.
- Botão para abrir o endereço do ponto de coleta no Google Maps.
- Rastreamento demonstrativo de pedidos.
- Cadastro de parceiros operacionais.
- Painel comercial com histórico de cotações, buscas, rastreamentos e parceiros.
- Dados salvos no navegador com localStorage.
- HTML, CSS e JavaScript comentados.

## Como testar

1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` no navegador.
3. Simule uma cotação de frete.
4. Busque um ponto de coleta por CEP na página `agencia-proxima.html`.
5. Cadastre um parceiro em `cadastrar-motorista.html`.
6. Consulte os registros em `admin.html`.

## Observação técnica

Esta versão foi feita apenas com HTML, CSS e JavaScript, conforme a proposta de front-end funcional sem backend. Os dados ficam salvos localmente no navegador do usuário por meio do localStorage.
