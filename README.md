# Projeto HTML, CSS e JavaScript - Equipe03

Projeto acadêmico de uma página comercial para entrega de encomendas.

## Estrutura

- `index.html`: página inicial
- `cadastrar-motorista.html`: página de cadastro de motorista parceiro
- `agencia-proxima.html`: página para buscar agência próxima
- `css/style.css`: estilos do projeto
- `js/script.js`: interações em JavaScript
- `img/`: imagens utilizadas no projeto

## Como rodar

Abra o arquivo `index.html` no navegador.

## Como atualizar no GitHub

```bash
git add .
git commit -m "Atualiza nova versão do projeto"
git push
```
